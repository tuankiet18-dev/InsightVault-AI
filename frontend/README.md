# InsightVault AI Frontend

React + Vite frontend for the InsightVault AI MVP.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Structure

- `src/App.tsx`: MVP dashboard shell.
- `src/data/`: static MVP data used by the current UI.
- `src/types/`: shared frontend TypeScript types.
- `src/assets/`: local visual assets.

This is still a static shell. API integration should use the backend endpoints under
`backend/InsightVault.API`.
